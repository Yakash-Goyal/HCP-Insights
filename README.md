# HCP Insights & Segmentation

Analyzes physician-payment data to identify high-priority healthcare providers
(HCPs) for targeted engagement.

## What It Does

1. Uses SQL to profile payment records by specialty, state, payment type,
   company, and HCP.
2. Uses Python/Pandas to create an RFM-style score for each HCP:
   recency, frequency, and value.
3. Exports CSV files that can be used later in a Power BI dashboard.

## Data

The repo includes `data/sample_payments.csv`, a synthetic dataset generated by
`generate_sample_data.py`. It contains 4,000 payment records across 500 HCPs.

| Column | Description |
|---|---|
| physician_id | Unique HCP identifier |
| physician_specialty | HCP specialty |
| physician_state | US state |
| payment_date | Date of payment |
| payment_amount | Payment amount in USD |
| payment_type | Type of payment |
| paying_company | Company making the payment |

## How To Run

```bash
pip install -r requirements.txt
python generate_sample_data.py
python notebooks/rfm_segmentation.py
```

The Python script writes:

| Output | Purpose |
|---|---|
| `output/hcp_segments.csv` | HCP-level RFM scores and priority segment |
| `output/segment_summary.csv` | Count and value by priority segment |
| `output/specialty_summary.csv` | Specialty drill-down table |
| `output/regional_gap_summary.csv` | Simple state-level gap table |
| `output/top_hcps.csv` | Top 50 HCPs |

For dashboard creation, see `powerbi/README.md`.
